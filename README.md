# VS 云音乐 (VS Cloud Music)

在 Vintage Story 里播放你自己的在线音乐 —— 搜索、歌单、每日推荐、私人电台，
外加常驻的播放状态 HUD。

游戏内按 **`L`** 打开播放器面板。

> **已知问题**：低音较重的曲目会有「炸音」（听感像低音炮拍手）。
> 详见 [已知问题](#已知问题)。

---

## 功能

| | 说明 |
|---|---|
| **搜索** | 关键词搜索，每页 50 首，「更多」翻页 |
| **歌单** | 读取当前账号的歌单，整张灌入播放队列 |
| **每日推荐** | 服务端个性化推荐 |
| **电台** | 私人 FM，队列见底时自动续取（网易接口每次只给 3 首，故为必需） |
| **播放模式** | 单曲循环 / 顺序 / 随机（随机模式下上一首同样随机） |
| **播放控制** | 上一首、下一首、暂停/继续、音量 |
| **播放队列** | 显示完整队列并标出正在播放的那首；允许跨音乐源混排 |
| **HUD** | 封面 + 歌名 + 进度条 + 时间，常驻屏幕左上角，面板打开时自动隐藏 |
| **扫码登录** | 游戏内显示二维码，手机 App 扫码即可；也可退出登录 |
| **多音乐源** | 第三方模组可注册别的音乐源（见 [扩展开发](#扩展开发)） |

面板底部的功能入口会**按当前音乐源的能力自动显隐** —— 不支持推荐/电台的音源，
对应按钮不会出现。

## 安装

1. 把 `WyyPlayer.zip` 解压到游戏的 `Mods/` 目录（或直接放入 zip）。
2. 启动游戏，按 `L` 打开面板。
3. 点「音源」→「登录」，用手机 App 扫码。

### 从旧版本升级

模组 id 在 0.1.0 时由 `wyyplayer` 改为 `vscloudmusic`，**Mods 目录名也随之改变**。
升级时请**先删掉旧的 `Mods/wyyplayer/` 目录**，否则两个版本会同时加载、
共用同名程序集而报「Assembly with same name is already loaded」。

设置（播放模式、音量、HUD 位置）也会重置一次 —— 配置文件名随 id 改变。

### 依赖

- **Vintage Story 1.22.7**（客户端）
- 无需安装任何额外软件。音源解码与二维码编码都是纯托管实现。

## 使用

| 按键/操作 | 作用 |
|---|---|
| `L` | 打开/关闭播放器面板 |
| 面板「音源」 | 查看已注册的音乐源、登录状态，或登录/退出 |
| 面板「推荐」「电台」「歌单」 | 切换内容来源（列表会缓存，切回来不重取） |
| 面板「队列」 | 查看当前播放队列 |
| 音量 / 进度 | 面板底部的滑块 |

**关于电台**：网易的私人 FM 接口每次只返回 3 首，因此队列见底时会自动再取一批 ——
这与官方客户端的行为一致。

**关于列表缓存**：电台列表在「电台仍在播放」时切走再切回会保留；
如果你中途去听了歌单或搜索的结果，再回到电台会换一批（因为上一批电台在语义上已经结束）。

## 已知问题

### 低音炸音

低音较重的曲目会有「炸音」，听感类似低音炮拍手。**MPV 等播放器播放同一文件没有问题，
只有经由本模组的播放通道才出现。**

已经排查并**排除**的方向（均有实测依据）：

| 方向 | 结论 | 依据 |
|---|---|---|
| 解码 | 排除 | 源 PCM 干净（峰值 32755、零触顶、直流偏移 2.41、波峰因数 12.7 dB）；两个不同解码器解出的 WAV 用 MPV 播放均正常 |
| 削波 | 排除 | 录屏音频零触顶、无静音断口、瞬态间隔不规则（非周期性故障） |
| 电平 / 喇叭行程 | 排除 | 次声波高通拉到 80 Hz 无效 |
| 3D 定位（多普勒、距离衰减） | 排除 | 声源设为 listener 相对后无改善 |
| 独立 OpenAL 上下文（关闭 HRTF） | 排除 | 自建设备与上下文后无改善 |
| 外部播放器（mpv） | **有效** | 播放完全正常，但需要用户额外安装，不满足单包分发 |

结论：问题定位在「经由游戏 OpenAL 通道」这一环，但**具体成因尚未查明**。
若你有相关经验，欢迎提 issue。

## 从源码构建

```bash
export VINTAGE_STORY=/path/to/VintageStory      # 游戏安装目录
dotnet build -c Release
dotnet test
```

产物在 `src/WyyPlayer/bin/Release/Mods/mod/`，连同 `modinfo.json` 与 `assets/`
一起打包为 zip 即可分发。

### 工程结构

```
src/WyyPlayer.Api      音乐源扩展契约（纯契约，无实现、无网络、无游戏引用）
src/WyyPlayer.Core     可离线单测的核心：加密、HTTP、接口解析、解码、队列、缓存
src/WyyPlayer          模组本体：游戏集成、UI、音频输出
tests/                 Core 的单元测试
tools/                 接口探针与游戏内验证脚本
docs/                  设计与计划文档
```

**分层原则**：`Core` **禁止引用任何游戏程序集** —— 这是它能脱离游戏做离线单测的前提。
它通过 `ILog` 这样的小接口与游戏层解耦。

## 扩展开发

第三方模组可以注册额外的音乐源（QQ 音乐等）。契约在 `WyyPlayer.Api`：

```csharp
// 在你自己的 ModSystem.StartClientSide 里
var wyy = api.ModLoader.GetModSystem<WyyPlayerMod>();
wyy.RegisterProvider(new MyQqMusicProvider());
```

加载顺序交给 Vintage Story 自己的模组系统（`modinfo.json` 的 `dependencies`），
本模组不做插件加载器。

详见 [`docs/provider-api.md`](docs/provider-api.md)。
